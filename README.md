# Automatiza Solar — Demo de panel de leads

Demo interactiva de un solo archivo (`index.html`, sin build ni dependencias): panel de leads + simulador de conversación estilo WhatsApp (visual, no es WhatsApp real) para mostrar en llamadas de venta.

## Uso

- Abre la web y verás el panel con las personas que han preguntado, sus estados y las estadísticas del mes.
- El lead marcado como "Solo curiosidad" (Andrés Zapata) tiene un botón para simular la conversación de recuperación.
- "Reiniciar demo" vuelve todo al estado inicial para repetir el flujo en cada llamada.

## Deploy

Sitio 100% estático — en Vercel se despliega sin configuración (Framework Preset: *Other*).
